# Skill Compare Template

Use when two or more creators teach the same skill. Keep only what actually works.

```markdown
# Compare: (skill name)

## Contenders

| Creator | Source | Core claim |
|---|---|---|
| @a | (link) | (what they teach) |
| @b | (link) | (what they teach) |

## Head-to-head

- **Where they agree:** ...
- **Where they differ:** ...
- **What A gets right that B misses:** ...
- **What B gets right that A misses:** ...

## Verdict

Keep: (winner and why)
Merge: (anything worth salvaging from the loser)
Drop: (loser)
```
```

Rule: the collection holds exactly one best version of each skill.
If neither wins outright, merge the best parts into a single card and drop both originals.
