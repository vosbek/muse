# Project Setup Template

Copy this file into `setups/` as `project-name.md`. Stack the skills the project needs,
then paste the whole thing into your AI tool so it starts with the playbook.

```markdown
# Setup: (project name)

## What I'm building

(one-liner)

## Skills in this stack

- [ ] (skill 1 — link to its card in skills/)
- [ ] (skill 2 — link to its card in skills/)
- [ ] (skill 3 — link to its card in skills/)

## The playbook

(Paste the distilled instructions here — the actual prompt / system text /
project brief your AI should follow. This is the part you hand to the model.)

## Notes

(anything learned while running this setup — feed improvements back
into the skill cards so the collection gets sharper)
```
